# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant], which is the
code of conduct most contributors will already know. The canonical text is linked
rather than copied here, so that it cannot drift from the version it claims to be.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## In short

Be respectful. Assume good faith. Critique code, not people. Harassment, insults and
personal attacks are not acceptable, in issues, pull requests, discussions or
anywhere else this project is represented.

## Scope

It applies in all project spaces — this repository, its issues, pull requests and
discussions — and whenever someone is representing the project in public.

## Enforcement

Report unacceptable behaviour privately to **hello@noidee.dev**. Reports are handled
confidentially, and we will not discuss a report with anyone beyond what is needed to
resolve it.

The maintainers may warn, temporarily restrict, or permanently ban anyone whose
behaviour they judge inappropriate, and will say why when they do.

If your report concerns a maintainer, say so in the message; we would rather hear it
than not.

## Security reports go elsewhere

A vulnerability is not a conduct matter. See [SECURITY.md](SECURITY.md) for how to
report one privately.
