# `ddev sync init`, part A — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ddev sync init` as far as writing one verified target, so that the three places telling users to run it stop lying.

**Architecture:** PyYAML renders the *new* target block and never sees the user's file, so no comment is ever at risk; plain text operations place that block. Because placing it can go wrong, the whole configuration is parsed through the real loader before and after, and a mismatch restores the file. The wizard's questions are thin wrappers over `questionary`, as `cli/prompts.py` already does, and the final verification is `doctor_command` called as it stands.

**Tech Stack:** Python 3.12, click, questionary, PyYAML, pydantic, uv, pytest.

**Spec:** `docs/specs/2026-10-07-sync-init-design.md`. Read it for the reasoning and for what part B deliberately leaves out.

## Global Constraints

- Tests: `uv run pytest`. Coverage gate is **100 % line and branch** (`--cov-fail-under=100`, `branch = true`); `# pragma: no cover` is forbidden anywhere in the project.
- `uv run ruff check . && uv run ruff format --check . && uv run mypy src tests` must pass. Ruff line length is 100.
- `subprocess` may only be imported in `src/ddev_sync/transport/runner.py`; an AST-parsing test enforces it.
- Everything code-side is English, including every string `init` prints. There is no i18n layer.
- Conventional Commits. Every message ends with `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`. Write it to a file and use `git commit -F <file>`; never nest a heredoc inside another.
- Comments explain *why*, not *what*, and must be **true of the code beside them**. On the two previous plans in this repo the reviews found roughly a dozen comments that stated something the code did not do, most of them copied from the plan's own prose — so read this plan's wording critically and report anything that does not hold rather than copying it.
- **PyYAML must never parse the user's configuration file in order to write it.** It renders new blocks only. Round-tripping a document through `safe_load`/`safe_dump` destroys every comment, and the add-on ships that file full of them.
- `init` writes exactly one file per run. Part A never touches `.ddev/ddev-sync.local.yaml`.
- Never infer a stage from a host name. The spec and §9 of the matrix findings both state this: some projects name hosts `production`/`staging`, others name them after machines.

```python
"""Place one target into one configuration layer, leaving the rest alone.

Nothing else in this engine writes configuration, so the mechanism is a
choice rather than a pattern to follow. It is text, not YAML: the add-on
installs `.ddev/ddev-sync.yaml` from a template full of explanatory comments
(`install.yaml`), and a `safe_load`/`safe_dump` round trip would delete every
one of them. PyYAML still renders the *new* block - quoting is a solved
problem and not worth re-solving - but it never parses the user's file.

What makes text surgery acceptable is `write_target`'s check: the whole
configuration is read through the real loader before and after, every other
target must resolve identically, and anything else restores the file. So the
scan below may fail on flow-style mappings, anchors or tabs without having to
recognise them.
"""

from collections.abc import Mapping
from pathlib import Path
from textwrap import indent
from typing import Any

import yaml

from ddev_sync.config.loader import ConfigPaths, load_user_layers
from ddev_sync.config.targets import collect_targets
from ddev_sync.errors import DdevSyncError

TARGETS_KEY = "targets"
_INDENT = "  "


class WriteRefused(DdevSyncError):
    """The write was undone because it could not be proved correct."""


def render_target(name: str, fields: Mapping[str, Any]) -> str:
    """The YAML lines for one target, indented to sit under `targets:`.

    `sort_keys=False` keeps the order the caller chose, which is the order a
    person reads: where the host is, who connects, which stage it is.
    """
    body = yaml.safe_dump({name: dict(fields)}, default_flow_style=False, sort_keys=False)
    return indent(body, _INDENT)


def place_target(document: str, name: str, block: str) -> str:
    """Return `document` with `block` as the `name` target under `targets:`."""
    lines = document.splitlines(keepends=True)
    start = _targets_line(lines)
    if start is None:
        separator = "" if document.endswith("\n") or not document else "\n"
        return f"{document}{separator}\n{TARGETS_KEY}:\n{block}"
    existing = _target_line(lines, start, name)
    if existing is None:
        end = _block_end(lines, start)
        return "".join(lines[:end]) + block + "".join(lines[end:])
    end = _block_end(lines, existing)
    return "".join(lines[:existing]) + block + "".join(lines[end:])


def write_target(*, path: Path, paths: ConfigPaths, name: str, block: str) -> None:
    """Place `block` in `path`, then prove it through the real loader.

    `original` is held in memory rather than written to a backup file: a
    failed write must leave nothing behind at all, and a stray
    `ddev-sync.yaml.bak` is something behind.
    """
    before = _targets(paths)
    original = path.read_text(encoding="utf-8") if path.exists() else None
    document = original if original is not None else "version: 1\n"
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(place_target(document, name, block), encoding="utf-8")
    try:
        after = _targets(paths)
    except DdevSyncError as error:
        _restore(path, original)
        raise WriteRefused(
            f"writing the target {name!r} to {path} produced a file the loader "
            f"rejected, so nothing was changed: {error}"
        ) from error
    if name not in after:
        _restore(path, original)
        raise WriteRefused(
            f"the target {name!r} is not there after writing it to {path}, so "
            "nothing was changed"
        )
    changed = [other for other, spec in before.items() if other != name and after.get(other) != spec]
    if changed:
        _restore(path, original)
        raise WriteRefused(
            f"writing the target {name!r} to {path} would also have changed "
            f"{', '.join(sorted(changed))}, so nothing was changed"
        )


def _targets(paths: ConfigPaths) -> dict[str, Any]:
    # `collect_targets` takes the layers themselves and does its own merging
    # (`config/targets.py:42`), so nothing here merges them first.
    collected = collect_targets(load_user_layers(paths))
    return {name: entry.spec for name, entry in collected.items()}


def _restore(path: Path, original: str | None) -> None:
    if original is None:
        path.unlink(missing_ok=True)
        return
    path.write_text(original, encoding="utf-8")


def _targets_line(lines: list[str]) -> int | None:
    """The index of an uncommented `targets:` at the top level, if any."""
    for index, line in enumerate(lines):
        if line.rstrip("\n") == f"{TARGETS_KEY}:":
            return index
    return None


def _target_line(lines: list[str], start: int, name: str) -> int | None:
    for index in range(start + 1, _block_end(lines, start)):
        if lines[index].rstrip("\n") == f"{_INDENT}{name}:":
            return index
    return None


def _block_end(lines: list[str], start: int) -> int:
    """The index just past the block that begins at `start`.

    A blank or comment line does not end a block: it may sit between two
    targets, and treating it as the end would insert the new target in the
    middle of someone's comment.
    """
    opening = len(lines[start]) - len(lines[start].lstrip())
    for index in range(start + 1, len(lines)):
        stripped = lines[index].strip()
        if not stripped or stripped.startswith("#"):
            continue
        if len(lines[index]) - len(lines[index].lstrip()) <= opening:
            return index
    return len(lines)
```

`collect_targets(layers: Sequence[LayerDoc]) -> dict[str, CollectedTarget]` is the real signature — it merges the layers itself, and each `CollectedTarget` carries `.spec` and `.source`. Pass `load_user_layers(paths)` straight into it.
